## 6. 已知陷阱

- 只有 Windows PowerShell 5.1（沒有 `pwsh`）；啟動器一定要用上面的**絕對路徑**，從哪個目錄執行都一樣。
- 不要在 PowerShell 5.1 用 `python -c "..."` 帶引號的程式碼（會被改寫）；需要檢查就用 `val lite gate`。
- `CUDA_VISIBLE_DEVICES=""` 會讓 checkpoint 相關測試失敗；跑 CPU 測試時讓 GPU 保持可見即可（測試本身不做 GPU 運算）。
- 啟動器預設 `-Rule fixed-steps`；忘了加 `-Rule fixed-epochs` 會變成跑 v0.2-lite 的規則並產生新的 `lite-czech-s<seed>-…` 目錄。每條命令先加 `-DryRun` 看 `plan` 那一行的 `rule=`、`seed=`、`reference=` 是否正確。
